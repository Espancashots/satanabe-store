# Satanabe Store v1

Site estático para clientes com:
- página de planos
- página de pagamento
- QR Code PIX com valor do plano
- PIX Copia e Cola com valor
- plano gratuito de 3 horas
- botão "Já fiz o pagamento" que abre o WhatsApp com mensagem pronta
- pedido local com código para facilitar o atendimento

## Publicar no GitHub Pages
Crie um repositório separado, por exemplo `satanabe-store`, e envie:
- index.html
- pagamento.html
- styles.css
- app.js

Depois ative:
Settings → Pages → Deploy from a branch → main → /(root)

## Observação
O pagamento é conferido manualmente. O site não libera a key automaticamente.
